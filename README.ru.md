# AutoScan

Диагностика автомобиля по OBD-II. Нативное приложение macOS.

## Запуск

```bash
open AutoScan.app
```

Пересобрать после правок:

```bash
./build_app.sh
```

## Проверка без машины

В комплекте эмулятор адаптера — он прикидывается Wi-Fi-донглом и «машиной»,
у которой стёрли ошибки перед продажей.

```bash
python3 Tools/mock_ecu.py --profile suspicious
```

Затем в приложении: **Подключить адаптер → Wi-Fi → пресет «Эмулятор» → Подключиться**.

Профили: `suspicious` (стёртые ошибки, пропуски в 3-м цилиндре) и `clean` (здоровая машина).

Headless-прогон всего цикла с печатью в терминал:

```bash
AutoScan.app/Contents/MacOS/AutoScan --selftest tcp:127.0.0.1:35000
```

## Подключение к настоящей машине

Зажигание должно быть включено — без него блоки не отвечают.

| Тип адаптера | Как подключить |
|---|---|
| **Wi-Fi** | Подключиться к сети адаптера в системных настройках, затем вкладка Wi-Fi, обычно `192.168.0.10:35000` |
| **USB** | Вкладка «USB / порт», выбрать `/dev/cu.usbserial-*` |
| **Bluetooth classic** | Сначала спарить в системных настройках, потом появится во вкладке «USB / порт» |
| **Bluetooth LE** | Вкладка «Bluetooth LE», поиск идёт автоматически |

## Что приложение делает

**Проверка автомобиля** — опрашивает всё, что отдаёт стандарт:

- список поддерживаемых параметров (узнаёт у самой машины, а не по справочнику)
- статус Check Engine и мониторов готовности
- коды ошибок трёх типов: подтверждённые (Mode 03), ожидающие (07), постоянные (0A)
- стоп-кадр — условия в момент возникновения ошибки (Mode 02)
- бортовые тесты, включая счётчики пропусков воспламенения по цилиндрам (Mode 06)
- VIN, версия прошивки блока и её контрольная сумма (Mode 09)
- показания всех доступных датчиков

Затем интерпретирует: связывает данные в выводы понятным языком.
Главный сценарий — **распознавание стёртых перед продажей ошибок**
по трём независимым уликам: пробег и время с момента сброса, незавершённые
мониторы, постоянные коды при пустой основной памяти.

**Мониторинг** — живые графики любых поддерживаемых параметров, выгрузка в CSV.

**Экспорт** — PDF со всеми расшифровками, CSV показаний, сырой журнал обмена.

## Границы

Это generic OBD-II: **двигатель и система снижения выбросов**.

ABS, подушки безопасности, коробка передач по этому протоколу недоступны —
у каждой марки там свои закрытые адреса и таблицы кодов. Для них нужен
сканер с доступом к этим блокам.

Дешёвые клоны ELM327 теряют кадры и игнорируют часть запросов. Если данные
читаются через раз — это ограничение железа. Всё, что не прочиталось,
приложение честно перечисляет в разделе «Что прочитать не удалось»,
а не подставляет вместо этого выдуманные значения.

## Структура

```
Sources/AutoScan/
├── Core/         транспорт (TCP/Serial/BLE) и протокол ELM327
├── Data/         таблица параметров, база кодов ошибок, мониторы
├── Engine/       сессия, движок проверки, логика выводов, самотест
├── Export/       генератор PDF
├── UI/           экраны
└── L10n/         русский и английский
Tools/mock_ecu.py эмулятор адаптера
```
